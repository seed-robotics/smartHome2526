# Challenges and Solutions

This folder contains optional Arduino practice, complete sample code, and the original kit material.

- [Challenges](Challenges/README.md) describes five small tasks for each lesson in plain language.
- [Solutions](Solutions/) contains one complete Arduino sketch for every challenge, organized in folders that open directly in the Arduino IDE.
- [Complete lesson sketches](../LessonMaterial/Solutions/) provide a finished example for each lesson.
- [Original exercises, solutions, lesson plan, and wiring images](ExercisesAndSolutions/) are kept together here.

The challenge and lesson solution sketches use example pin assignments. Check the wiring diagrams and change the pin constants if your kit is wired differently. Some lessons require a library or a teacher-approved kit setup; each sketch notes this near the top. Always follow the kit guide and teacher instructions. Never connect a relay to mains electricity. The gas sensor is not a safety alarm.
